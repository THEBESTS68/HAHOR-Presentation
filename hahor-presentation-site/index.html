01 / THE PROBLEM

จาก Pain Point
สู่โอกาสในการออกแบบ

จากเอกสาร HAHOR ปัญหาหลักคือข้อมูลหอพักกระจัดกระจาย ติดต่อยาก ภาพไม่ตรงปก ข้อมูลไม่อัปเดต และผู้ใช้กังวลเรื่องความปลอดภัย

🔎

ค้นหายาก

  • ข้อมูลหอพักกระจัดกระจาย
  • ใช้เวลาค้นหานาน
  • ต้องเดินทางไปดูหลายแห่ง
❗️

ข้อมูลไม่น่าเชื่อถือ

  • ภาพประกอบไม่ตรงปก
  • ข้อมูลอาจไม่อัปเดต
  • ไม่รู้คุณภาพจริงของหอพัก
🏡

ความปลอดภัย

  • กังวลเรื่องความปลอดภัย
  • อยากเห็นรีวิวจากผู้พักจริง
  • ต้องการข้อมูลที่ช่วยตัดสินใจ

03 / USER FLOW

เส้นทางที่สั้น
และเข้าใจง่าย

User Flow ในเอกสารแบ่งเป็น 7 ขั้น: เปิดแอป → เข้าสู่ระบบ → ค้นหาที่พัก → ดูรายละเอียด → รีวิว → จองที่พัก → จองสำเร็จ

1️⃣เปิดแอปเข้าสู่ HAHOR
2️⃣เข้าสู่ระบบLogin / Sign up
3️⃣ค้นหาที่พักค้นหาจากแผนที่
4️⃣รายละเอียดดูข้อมูลหอ
5️⃣รีวิวตรวจสอบความคิดเห็น
6️⃣จองที่พักเลือกและยืนยัน
7️⃣จองสำเร็จConfirmation
04 / PRODUCT IDEA

Feature ที่ตอบ
โจทย์จริง

แนวคิดในเอกสารเน้นการค้นหา เปรียบเทียบ รีวิว การติดต่อ และความปลอดภัย รวมถึงการนำ AI มาช่วยพัฒนาความปลอดภัยและเสถียรภาพของแอป

📍

แผนที่แบบเรียลไทม์

ค้นหาหอพักตามทำเลและมองภาพพื้นที่ได้ง่ายขึ้น

⭐️

รีวิวจากผู้เช่าจริง

ใช้ข้อมูลจากผู้ใช้งานเพื่อประกอบการตัดสินใจ

💬

แชทในระบบ

ติดต่อเจ้าของหอพักและผู้เช่าได้สะดวก

❗️

แจ้งเหตุ / เตือนภัย

เพิ่มช่องทางสำหรับการแจ้งเหตุอย่างรวดเร็ว

📜

ติดตามสถานะค่าใช้จ่าย

แนวคิดการติดตามสถานะค่าใช้จ่ายแบบเรียลไทม์

AI

AI เพื่อความปลอดภัย

เอกสารเสนอการใช้ AI เพื่อค้นหาช่องโหว่และช่วยให้ระบบปลอดภัยและเสถียร

05 / CUSTOMER SEGMENT

หนึ่งแพลตฟอร์ม
หลายกลุ่มผู้ใช้

งานระบุกลุ่มลูกค้าหลักทั้งฝั่งผู้เช่าและเจ้าของหอพัก โดยมีความต้องการแตกต่างกันแต่เชื่อมต่อกันในแพลตฟอร์มเดียว

01 / TENANT

นักเรียนและนักศึกษา

หาหอใกล้มหาวิทยาลัย งบจำกัด ใช้สมาร์ทโฟนเป็นประจำ ต้องการค้นหาและเปรียบเทียบได้ง่าย

02 / WORKER

พนักงานบริษัท / First Jobber

ค้นหาที่พักใกล้ที่ทำงาน เน้นการเดินทาง ความปลอดภัย ราคา และสิ่งอำนวยความสะดวก

03 / MOVER

ผู้เช่าเดิมที่ต้องการย้าย

ต้องการเปลี่ยนที่พัก เปรียบเทียบหลายแห่ง และดูรายละเอียดพร้อมรีวิว

04 / OWNER

เจ้าของกิจการหอพัก

เพิ่มช่องทางประชาสัมพันธ์ เพิ่มผู้เช่า และจัดการข้อมูลหอพักได้ง่ายขึ้น

06 / PLATFORM

From Persona
to Platform

แนวคิด HAHOR ถูกวางให้เป็นจุดเชื่อมระหว่างความต้องการของผู้เช่า ข้อมูลหอพัก และเครื่องมือสำหรับการตัดสินใจ

DESIGN PRINCIPLE

“ลดความวุ่นวายของการหาหอ ให้เหลือเป็นเส้นทางที่ชัดเจน ค้นหา → เปรียบเทียบ → ตรวจสอบ → ติดต่อ → จอง”
