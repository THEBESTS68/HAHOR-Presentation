HAHOR Presentation Website
==========================
1. Keep all files in this folder.
2. Open index.html in Chrome/Edge.
3. The site uses the supplied LINE Seed Sans Thai font files.
4. The visual direction is based on the supplied HAHOR Concept and User Flow/Wireframe PDFs:
   - sky blue / deep navy / mint palette
   - rounded cards, soft shadows, organic corner shapes
   - HAHOR logo direction
   - Persona, Customer Segment, User Flow and Feature content
